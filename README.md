# АрбитрПро — PWA личного кабинета должника

Демо-версия личного кабинета для должников.

## Тестовые аккаунты

| ИНН | СНИЛС | Сценарий |
|---|---|---|
| 502712345678 | 123-456-789 01 | Активное дело (главный экран) |
| 770123456789 | 987-654-321 00 | Жёсткая блокировка (Госуслуги) |
| 771234567890 | 555-666-777 88 | Мягкая блокировка (запрос документов) |
| 500123456789 | 111-222-333 44 | Дело завершено |

## Деплой на GitHub Pages

1. Создайте репозиторий `arbitrpro-pwa` на GitHub
2. Загрузите все файлы в корень репозитория
3. Settings → Pages → Source: `main` branch, `/ (root)`
4. Через 1-2 минуты сайт будет доступен по адресу:
   `https://<ваш-логин>.github.io/arbitrpro-pwa/`

## Установка на телефон

1. Откройте сайт в Safari (iOS) или Chrome (Android)
2. iOS: «Поделиться» → «На экран «Домой»»
3. Android: меню → «Добавить на главный экран»
4. Приложение появится как нативное

## Фирменные цвета

- Зеленый: `#1B8A4A` (основной)
- Белый: `#FFFFFF`
- Бежевый: `#FAF6ED` (фон)
- Золотой: `#C9A961` (акцент)

## Что реализовано

- ✓ Экран входа с маской СНИЛС
- ✓ Главный экран с трекером ПМ и дела
- ✓ Жёсткая блокировка (Госуслуги)
- ✓ Мягкая блокировка (запрос документов)
- ✓ Форма доп. пополнения с загрузкой фото
- ✓ Экран завершённого дела
- ✓ Демо-панель управления статусами
- ✓ PWA-манифест (установка на главный экран)
- ✓ Service Worker (офлайн-режим)
- ✓ Адаптив под мобильные

## Что требует доработки в продакшене

- Реальный бэкенд и авторизация
- Интеграция с Госуслугами
- Push-уведомления
- Чат с поддержкой
- Загрузка документов на сервер
